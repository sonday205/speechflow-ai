# SpeechFlow AI Frontend

React + Vite + Tailwind CSS frontend for SpeechFlow AI.

## Setup

```powershell
cd frontend
npm install
copy .env.example .env
```

## Run

```powershell
npm run dev
```

Frontend runs at:

```txt
http://localhost:5173
```

## Environment

```env
VITE_API_BASE_URL=http://localhost:8000
VITE_WS_BASE_URL=ws://localhost:8000
```

## Build

```powershell
npm run build
```
